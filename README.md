# Ters Şiir Üreteci

## Bu Nedir?

Bu, dünyanın en ciddi, en bilimsel, en akademisyen onaylı **gereksiz** projesidir.  
Cümleleri kelime kelime ters çevirir, sonra onlardan şiir üretir.  
Kelimeler intikam alır. Anlam kaçar. Şiir ağlar.

> "Her şey tersine dönebilir. Özellikle anlam."

## Neden Var?

Çünkü normal şiir üreticileri çok sıkıcı.  
Biz ise cümleleri işkence ediyoruz. Bilim için. Sanat için. Can sıkıntısı için.

## Nasıl Kullanılır?

```bash
python siir_makinesi.py "bugün çok mutluyum"
```

Çıktı şuna benzer bir şey olur:

```
=== ORİJİNAL CÜMLE ===
bugün çok mutluyum

=== TERS ÇEVRİLMİŞ ===
nügub koç muyutlum

=== ÜRETİLEN ŞİİR ===
Ah nügub koç muyutlum, ne büyük trajedi!
Kelimeler ters döndü, dünya çöktü.
```

Evet, bu kadar. Başka bir şey yapmaz. Yapmasına da gerek yok.

## Özellikler

- %100 çalışır (Python 3 ile)
- Hiçbir şey öğrenmez
- Hiçbir şey kaydetmez
- Sadece ters çevirir ve şiir yazar
- Rastgele derin düşünceler ekler
- Dünyayı daha anlamsız yapar (garanti)
